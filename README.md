# 📊 Customer Churn Prediction

## 📌 Project Overview

Customer churn is an important business problem for telecom companies.
This project uses Machine Learning to predict whether a customer is
likely to churn based on customer and service-related information.

## 🎯 Objective

The objective of this project is to build a classification model
that predicts customer churn and helps identify factors associated
with customer churn.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Jupyter Notebook

## 📂 Dataset Features

The project uses customer information such as:

- Tenure
- Monthly Charges
- Total Charges
- Contract
- Internet Service
- Payment Method

### Target Variable

**Churn**

- Yes → Customer churned
- No → Customer did not churn
